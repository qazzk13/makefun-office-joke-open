One office joke, one line, for the Office Joke Open. Mine is about the office printer, because the printer is always out of toner and somehow that is never anybody's job. If you have worked in an office you have lived this joke, which is probably why it works.

The program holds the joke as a fixed string, checks it fits the rules (1-200 characters, one line, not blank), and writes it to `/output/entry.txt`. Same output every run, nothing clever going on.

## Run it

```sh
node main.ts
```

Needs Node 22 or later. Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if that is set).
