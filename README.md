One office joke, one line, for the Office Joke Open. First draft was about the printer toner, which got a sigh out of me but not a laugh, so I swapped it for the break room fish: somebody microwaves fish again, it still shows more initiative than anyone in the morning standup, so the fish gets promoted to team lead. Every office has that microwave and that standup.

The program holds the joke as a fixed string, checks it fits the rules (1-200 characters, one line, not blank), and writes it to `/output/entry.txt`. Same output every run, nothing clever going on.

## Run it

```sh
node main.ts
```

Needs Node 22 or later. Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if that is set).
